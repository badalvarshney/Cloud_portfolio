# Cloud Portfolio ☁️

A modern, high-performance monochromatic Cloud Portfolio built with **React**, **Vite**, **Three.js**, **GSAP**, and **Tailwind CSS**.

## 🚀 Tech Stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Animations**: GSAP & Framer Motion
- **3D / Visual Effects**: Three.js & Vanta.js
- **Icons**: Lucide React

## 📦 Getting Started

### Installation

```bash
npm install
```

### Development

```bash
npm run dev
```

### Production Build

```bash
npm run build
```
